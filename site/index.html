backupctl

restic-based MySQL/PostgreSQL backups. A server dumps the databases, a client pulls them over SSH — no passwords, only a key.

$curl -fsSL https://raw.githubusercontent.com/Solo-it/backupctl/main/backupctl-install.sh | sh

See it in action

What it does

Server → restic repository

Dumps MySQL/PostgreSQL on a schedule (UTC, explicit systemd timer), backs them up with restic, installs restic itself if missing.

Client pulls, never pushes

The client fetches the repository over rsync via SSH. The server's backup-user has no password at all — key-only, restricted to rsync.

Cross-platform clients

launchd and pm2 on macOS, systemd on Linux, Task Scheduler on Windows — same config format everywhere.

Idempotent by design

Re-run --init-server any time — adding a database means editing the config and running it again, nothing destructive.

Install

Debian / Ubuntu curl -fsSL https://solo-it.github.io/backupctl/apt/signing-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/backupctl.gpg echo "deb [signed-by=/usr/share/keyrings/backupctl.gpg] https://solo-it.github.io/backupctl/apt stable main" | sudo tee /etc/apt/sources.list.d/backupctl.list sudo apt update && sudo apt install backupctl
Homebrew brew install Solo-it/tap/backupctl
Go go install github.com/Solo-it/backupctl/cmd/backupctl@latest
